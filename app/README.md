
# Internship Git and GitHub Task

## Project Overview

This repository is created as part of an internship assignment to demonstrate basic Git and GitHub concepts, repository management, branching strategies, and a sample web application.

- CSS
- JavaScript
- Git
- GitHub

## Sample Application

A simple Task Manager application built using HTML, CSS, and JavaScript.

### Features

- Add new tasks.
- Mark tasks as completed.
- Validate empty task input.
- Simple user interface.

## How to Run the Application

1. Clone this repository.
2. Open the `app` folder.
3. Open `index.html` in a web browser.
4. Start adding tasks.

## Git Branching Strategy

This project follows a basic Git branching workflow.

- `main`: Stable project code.
- `feature/*`: New features and improvements.
- Pull Requests: Review changes before merging.

Detailed branching instructions are available in `docs/BRANCHING.md`.
